Core Capabilities

Every emergency is handled through a structured, automated pipeline — from detection to final resolution report.

🎯
Stage 01 · Detect

AI-powered real-time monitoring analyzes live camera feeds to identify threats including fire, violence, accidents and suspicious activity.

⚡
Stage 02 · Decide

The orchestration layer classifies every confirmed incident as CRITICAL, HIGH or MEDIUM severity — selecting the correct response protocol instantly.

👥
Stage 03 · Assign

Right personnel are automatically dispatched. Security, medical, managers — each role mapped to incident type and notified via Gmail + SMS.

📡
Stage 04 · Coordinate

A centralized command dashboard keeps every deployed team aligned in real time with live status updates and task assignments.

📊
Stage 05 · Track

Every action logged with timestamps. Real-time activity feed, zone heatmaps and response performance metrics for full visibility.

📄
Stage 06 · Report

Automated incident reports generated and delivered to management with timelines, outcomes and data-driven recommendations.

Instant Notifications

The moment an incident is detected, staff are alerted via Gmail and SMS — zero manual calls required.

📧
Gmail Alerts
Every incident triggers an immediate email to all configured recipients with incident type, severity, location, confidence, and assigned personnel list. Configure via GMAIL_USER env var.
💬
SMS via Twilio
Real-time SMS alerts sent instantly to staff phones. Includes incident summary, location, and team deployed. Configure via TWILIO_ACCOUNT_SID env vars.

AI Detection Modules

Each detection module uses specialized algorithms tuned for hospitality environments.

🔥 Fire Detection
Multi-layer HSV color filtering with brightness validation, flicker analysis and edge irregularity checks. 8-frame confirmation window eliminates false alarms.
CRITICAL SEVERITY
🥊 Violence Detection
Farneback optical flow combined with frame-difference burst analysis detects sudden chaotic motion spikes via pure mathematical OpenCV analysis.
HIGH SEVERITY
🚗 Accident Detection
YOLOv8n detects vehicles and persons in real time. IoU overlap logic automatically flags collisions. Falls back to motion blob analysis when YOLO unavailable.
HIGH SEVERITY
🚨 Suspicious Activity
Crowd density monitoring, intrusion zone alerts, loitering timers and after-hours activity flagging powered by YOLO person counting.
MEDIUM SEVERITY

Auto-Assigned Personnel

The orchestration layer knows which staff to deploy based on incident type. All notified instantly.
